# willvinton.com

Will Vinton's personal site, plus the Springspot family: Springspot AI (from whv3rd/Springboard) at `/springspot/`, Springspot Security (same repo) at `/springspot/security/`, and Springspot Labs (this repo) at `/labs/`. The homepage's "Now building" section links all three. Deployed together to GitHub Pages by `.github/workflows/deploy.yml`.

- `TRACKING.md`: GA4 and GTM event tracking
- `SEO.md`: search setup (sitemap, robots.txt, structured data, share images), the audit, and the Search Console steps
